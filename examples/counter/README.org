The demonstration the notebook exists for: the macOS demo's counter, its
view unchanged, running on the simulator over the glimmer seam. Two
namespaces from [[https://github.com/statonjr/glitter-uikit-demo][glitter-uikit-demo]] come across — the registry, trimmed to

* The registry, trimmed

The macOS =demo.registry= had two halves: an /example registry/ (a hub window
that opens examples) and an /action pipeline/ (actions as data, one spec per
kind, one multimethod per kind). One screen needs no hub, so only the
pipeline comes across — and =event-value= and =core/set-dispatch!= go with the
hub, since they were the shape of glitter's event map. Under glimmer a button
delivers nothing but the click, so =execute-actions= is called directly.

#+begin_src clojure :tangle ../../src/demo/registry.clj :mkdirp true :comments link
(ns demo.registry
  "The open action pipeline: actions are data ([:action/inc]), each kind
  declares its spec and its interpretation, and execute-actions validates then
  runs a vector of them. Example namespaces require this — never demo.core."
  (:require [clojure.spec.alpha :as s]))

(defmulti action-spec
  "Spec for one action vector, dispatched on its kind. Each notebook
  defmethods its own kinds; no method means invalid — typos stay loud."
  first)

(s/def ::action (s/multi-spec action-spec (fn [g _] g)))
(s/def ::actions (s/coll-of ::action))

(defmulti run-action!
  "Interpret one action vector. `event` is whatever the caller passes (nil
  from a button — UIKit hands a click no payload)."
  (fn [_event action] (first action)))

(defmethod run-action! :default [_ action]
  (println "Unhandled action:" (pr-str action)))

(defn execute-actions
  "Validate `actions` against ::actions, then run each in order."
  [event actions]
  (when-not (s/valid? ::actions actions)
    (println "Invalid actions:" (s/explain-str ::actions actions)))
  (doseq [a actions] (run-action! event a)))
#+end_src

* The counter — the diff worth printing

Against =examples/counter/README.org= in the macOS demo:

- the =ns= requires: =glimmer.ratom=, =glimmer.core= and =glimmer-ios.core=
  (for its install side effect) join =demo.registry= and =spec.alpha= — "unchanged
  except the requires", as the introduction promised;
- =state= is a ratom (=r/atom=), so a deref during render subscribes the
  component and a =swap!= re-renders it. =swap!= itself is unchanged:
  =glimmer.ratom= rebinds =clojure.core/swap!= to dispatch on reactive cells;

  =:on-click #(reg/execute-actions nil [[…]])=;

* The smoke: a tap without a finger

=simctl= cannot tap. What it can do is run the app and show its stdout, so
the smoke does the tap from inside: a =future= sleeps a second, then posts —
through the backend's own =:schedule=, from a thread that is not the main
loop, which is the case the =swap-vals!= drain exists for — a thunk that walks
glimmer's instance tree to the =+ 1= button, fires
=sendActionsForControlEvents:= on it twice, and prints the state. The =future=
starts before =ui/run=, which never returns. Expected: ={:count 2}=.

The instance tree is glimmer's: a =:comp= node with one child, =:native= nodes
with a =:widget= pointer and a vector of child atoms.

#+begin_src clojure :tangle ../../src/demo/smoke.clj :mkdirp true :comments link
(ns demo.smoke
  "Runs the counter and taps + 1 twice from a worker thread, via :schedule."
  (:require [demo.examples.counter :as counter]
            [glimmer.core :as ui]
            [glimmer-ios.core :as ios]
            [glimmer-ios.ffi :as u]))

(defn- find-native
  "Depth-first search of glimmer's instance tree for a :native node matching pred."
  [inst-atom pred]
  (let [inst @inst-atom]
    (if (and (= :native (:type inst)) (pred inst))
      inst
      (some #(find-native % pred) (:children inst)))))

(defn- tap-plus-one-twice! []
  (if-let [btn (find-native (ios/root-inst)
                            #(and (= :button (:tag %)) (= "+ 1" (:label (:props %)))))]
    (do (u/send-actions! (:widget btn) u/EVENT-TOUCH-UP-INSIDE)
        (u/send-actions! (:widget btn) u/EVENT-TOUCH-UP-INSIDE)
        (println "smoke: tapped + 1 twice; state =" (pr-str @counter/state)))
    (println "smoke: no + 1 button found in the instance tree")))

(defn -main [& _]
  (future
    (Thread/sleep 1000)
    (println "smoke: posting from a worker thread")
    (ios/schedule! tap-plus-one-twice!))
  (ui/run counter/root :title "Counter smoke"))
#+end_src

* Live: nREPL into the running counter

The README's W^X section said an on-device nREPL stays a dev-only feature —
evaluating /downloaded/ code is what the App Store bans — and TODO 4 asked
for it anyway, because a notebook that can =swap!= a ratom on a phone from
Emacs is a different kind of notebook. The simulator shares the Mac's
loopback, so =localhost:7888= is the app; on the phone, =iproxy 7888 7888=
(libimobiledevice, in the Brewfile) forwards the same port over USB to the
phone's loopback.

** The =os.name= landmine, detonated

The obvious version — =(jolt.nrepl/start 7888)= before =ui/run= — died on
the simulator at once:

#+begin_example
Unhandled exception: socket() failed
  trace: jolt.nrepl/start (jolt/nrepl.clj:396)
#+end_example

Milestone 1 recorded that jolt reports =os.name= "Linux" on iOS and predicted
it would bite one milestone on; this is the bite. =jolt.nrepl= picks its
socket constants by that string: not-"mac" means Linux, so it ORs
=SOCK_CLOEXEC= (0x80000, Linux-only) into the socket type and lays out
=sockaddr_in= without Darwin's =sin_len= byte. Darwin's =socket()= answers
EINVAL. And =System/getProperty "os.name"= is special-cased upstream, so the
app cannot lie its way out. The fix belongs upstream (=sa-os-family= should
call =*ios= Darwin); until then the app owns the socket: a Darwin-correct
listener of its own, handing each accepted fd to jolt's handler through the
private seam (=ns-interns= reaches a private var; privacy is a compiler
check). Everything past =accept= — bencode, sessions, eval — is jolt's.

#+begin_src clojure :tangle ../../src/demo/repl.clj :mkdirp true :comments link
(ns demo.repl
  "The counter, with an nREPL server on 7888 — listening through this
  namespace's own Darwin-correct socket, served by jolt.nrepl's handler."
  (:require [demo.examples.counter :as counter]
            [glimmer.core :as ui]
            [jolt.ffi :as ffi]
            [jolt.nrepl]))

(def port 7888)

;; Darwin BSD sockets. Not jolt.nrepl's: those pick Linux constants and layout
;; whenever os.name is not "mac", and on iOS it is "Linux".
(ffi/defcfn c-socket     "socket"     [:int :int :int] :int)
(ffi/defcfn c-bind       "bind"       [:int :pointer :int] :int)
(ffi/defcfn c-listen     "listen"     [:int :int] :int)
(ffi/defcfn c-setsockopt "setsockopt" [:int :int :int :pointer :int] :int)
(ffi/defcfn c-accept     "accept"     [:int :pointer :pointer] :int :blocking)
(ffi/defcfn c-close      "close"      [:int] :int)

(def ^:private AF-INET 2)
(def ^:private SOCK-STREAM 1)
(def ^:private SOL-SOCKET 0xffff)     ; Darwin (Linux: 1)
(def ^:private SO-REUSEADDR 4)        ; Darwin (Linux: 2)

(defn- sockaddr
  "struct sockaddr_in, Darwin layout: sin_len, sin_family, port (BE), then the
  address — 127.0.0.1 for :loopback, 0.0.0.0 for :any (Wi-Fi: opt-in only)."
  [port bind]
  (let [sa (ffi/alloc 16)]
    (dotimes [i 16] (ffi/write sa :uint8 i 0))
    (ffi/write sa :uint8 0 16)
    (ffi/write sa :uint8 1 AF-INET)
    (ffi/write sa :uint8 2 (bit-and (bit-shift-right port 8) 0xff))
    (ffi/write sa :uint8 3 (bit-and port 0xff))
    (when (= bind :loopback)
      (ffi/write sa :uint8 4 127) (ffi/write sa :uint8 7 1))   ; :any leaves 0.0.0.0
    sa))

(defn- listen! [port bind]
  (let [fd (c-socket AF-INET SOCK-STREAM 0)]
    (when (neg? fd) (throw (ex-info "socket() failed" {:port port})))
    (let [opt (ffi/alloc 4)] (ffi/write opt :int 0 1) (c-setsockopt fd SOL-SOCKET SO-REUSEADDR opt 4) (ffi/free opt))
    (let [sa (sockaddr port bind)
          r  (c-bind fd sa 16)]
      (ffi/free sa)
      (when (neg? r) (c-close fd) (throw (ex-info "bind() failed" {:port port}))))
    (when (neg? (c-listen fd 16)) (c-close fd) (throw (ex-info "listen() failed" {:port port})))
    fd))

(defn- private-fn [sym] (var-get (get (ns-interns 'jolt.nrepl) sym)))

(defn start!
  "Listen on `port` — :loopback (default; USB via iproxy) or :any (Wi-Fi, an
  eval server on the LAN: opt in knowingly) — and serve each connection with
  jolt.nrepl's built-in handler on its own thread. Returns immediately."
  ([port] (start! port :loopback))
  ([port bind]
  (let [fd      (listen! port bind)
        handler ((private-fn 'build-handler) [])
        serve   (private-fn 'handle-conn)]
    (future
      (loop []
        (let [conn (c-accept fd ffi/null ffi/null)]
          (when (>= conn 0)
            (future (try (serve conn handler)
                         (catch :default e (println "nrepl conn error:" (ex-message e)) (c-close conn)))))
          (recur))))
    (println "demo.repl: nREPL on" (if (= bind :any) "0.0.0.0:" "127.0.0.1:") port "— swap! demo.examples.counter/state")
    nil)))

(defn -main [& _]
  (start! port)
  (ui/run counter/root :title "Counter (live)"))
#+end_src

A scripted client, for proof that does not need an editor: one =eval= op
over bencode, printing each reply until =done=.

#+begin_src clojure :tangle ../../scripts/nrepl-eval :mkdirp true
#!/usr/bin/env bb
;; scripts/nrepl-eval PORT CODE — one nREPL eval over bencode; prints the replies.
;; HOST=<phone ip> for Wi-Fi (default 127.0.0.1).
(require '[bencode.core :as b])
(let [[port code] *command-line-args*
      port (Integer/parseInt (or port "7888"))]
  (with-open [s (java.net.Socket. (or (System/getenv "HOST") "127.0.0.1") port)]
    (let [out (.getOutputStream s)
          in  (java.io.PushbackInputStream. (.getInputStream s))
          str-vals (fn [m] (into {} (map (fn [[k v]] [k (cond (bytes? v) (String. v)
                                                              (sequential? v) (mapv #(if (bytes? %) (String. %) %) v)
                                                              :else v)]) m)))]
      (b/write-bencode out {"op" "eval" "code" code "id" "1"})
      (.flush out)
      (loop [n 0]
        (let [m (str-vals (b/read-bencode in))]
          (println m)
          (when (and (< n 20) (not (some #{"done"} (get m "status"))))
            (recur (inc n))))))))

Two things the phone attempt taught before it worked:

- *Loopback is shared, so ports collide.* With the simulator's app still
  listening on the Mac's =127.0.0.1:7888=, =iproxy 7888:7888= bound
  =*:7888= on IPv6 and reported nothing; the client's =127.0.0.1= went to
  the simulator, which cheerfully went from 40 to 80 and reported
  =os.arch= "aarch64" — the simulator's native build, not the phone's
  =tpb64l=. Forward to a different local port (=iproxy 7889:7888=), or quit
  the simulator's app first.
- *=iproxy= is USB.* The phone was paired with Xcode over Wi-Fi
  (=transportType: localNetwork=), which =devicectl= is happy with and
  =usbmuxd= is not: =idevice_id -l= listed nothing, and every forwarded
  connection was reset. Plug the cable in. Wi-Fi would mean binding the
  server to =0.0.0.0= on a phone, which is not a thing to do.

** Over Wi-Fi, on purpose

USB is the safe default and the one =jolt proxy= serves; but the phone
lives on a hub that drops its keyboards when the phone is plugged in, and
ClojureDart's =flutter run= lets you pick a wireless device, so the notebook
should too. Since the app owns the socket, Wi-Fi is one byte in the
=sockaddr=: =0.0.0.0= instead of =127.0.0.1=. It is a separate namespace
(=demo.repl-wifi=, built with =WIFI=1 jolt live=) so an eval server on the
LAN is a decision made at build time and never by accident.

Finding the phone: =dscacheutil= returns one address for =iPhone.local=, and
on a cabled phone it is the /USB link's/ =169.254.x.x= — which answered, and
proved the bind, but is not Wi-Fi. Asking mDNS directly returns all of them:

** =jolt connect=

jolt ships the server side only — =jolt repl= is a /local/ REPL with no
=--connect= — so the terminal client is nREPL's own, =nrepl.cmdline=, run
through the =clj= that is already on the machine. =jolt connect= wraps it:
USB by default (=localhost:7889=, after =jolt proxy=), or
=HOST=$PHONE PORT=7888 jolt connect= over Wi-Fi.

** A faster =jolt connect=: babashka

=nrepl.cmdline= is a JVM: a couple of seconds of startup and a deps
resolution before the first prompt, every time. bb starts in tens of
milliseconds and already speaks bencode, and jolt's server needs nothing
more than =eval= — so the terminal client is thirty lines of bb. It prints
=out=, =err= and =value= as they arrive and tracks the namespace the server
reports, which is all a prompt needs.

#+begin_src clojure :tangle ../../scripts/nrepl-repl :mkdirp true
#!/usr/bin/env bb
;; scripts/nrepl-repl [HOST] [PORT] — a terminal REPL over nREPL, in babashka.
;; ^D to leave; the server keeps running.
(require '[bencode.core :as b])
(let [[host port] *command-line-args*
      host (or host (System/getenv "HOST") "127.0.0.1")
      port (Integer/parseInt (or port (System/getenv "PORT") "7889"))
      ->str (fn [v] (cond (bytes? v) (String. v "UTF-8")
                          (sequential? v) (mapv #(if (bytes? %) (String. % "UTF-8") %) v)
                          :else v))
      sock (try (java.net.Socket. host port)
                (catch java.net.ConnectException _
                  (binding [*out* *err*]
                    (println (str "nothing listening on " host ":" port " — is the app in the foreground? "
                                  "(iOS suspends backgrounded apps; `jolt wake` brings it forward)")))
                  (System/exit 1)))
      out  (.getOutputStream sock)
      in   (java.io.PushbackInputStream. (.getInputStream sock))
      rdr  (java.io.BufferedReader. (java.io.InputStreamReader. System/in))]
  (println (str ";; nREPL " host ":" port " — ^D to leave"))
  (loop [ns "user" id 0]
    (print (str ns "=> ")) (flush)
    (when-let [line (.readLine rdr)]
      (if (clojure.string/blank? line)
        (recur ns id)
        (do (b/write-bencode out {"op" "eval" "code" line "id" (str id) "ns" ns})
            (.flush out)
            (recur
              (loop [ns ns]
                (let [m (into {} (map (fn [[k v]] [k (->str v)]) (b/read-bencode in)))]
                  (when-let [o (get m "out")] (print o) (flush))
                  (when-let [e (get m "err")] (binding [*out* *err*] (print e) (flush)))
                  (when (contains? m "value") (println (get m "value")))
                  (let [ns (or (get m "ns") ns)]
                    (if (some #{"done"} (get m "status")) ns (recur ns)))))
              (inc id)))))))
#+end_src

Measured against the phone over Wi-Fi, one expression piped in, warm caches:
bb =0.11 s=, =nrepl.cmdline= =1.37 s=. So =jolt connect= is the bb client, and
the JVM one stays as =jolt connect-clj=.

(The first session also left a souvenir: =(swap! state assoc count 0)= with
=count= unquoted stores the /function/ as a key — ={:count 1, #object[clojure.core$count …] 0}=.
Harmless, since the view reads =:count=; =(swap! state dissoc count)= evicts it.)

** Suspended, not dead

Minutes after the Wi-Fi session, =jolt connect= got =Connection refused= —
with the process still listed on the phone. iOS had suspended it (screen
locked, or another app in front), and a suspended process's listener
accepts nothing. =jolt wake= — a =devicectl= relaunch, which works over Wi-Fi
— brings it to the foreground and the prompt returns. The client now says
so instead of a stack trace. This is TODO 2, lifecycle, making its first
appearance: keep the phone unlocked and the app in front for a session.

* The app as data (2026-09-01)

Paul deGrandis's shape — Vase, "Unlocking data-driven systems" — applied to
the counter: the shell ships once, and what it renders is a map,
={:state … :view …}=, that could have come from anywhere. Three small
namespaces: =demo.data= interprets the map, =demo.store= reads and writes
it in the app's Documents directory, =demo.app= is the =-main=. No =eval=
anywhere. The view is hiccup with two data conventions, each undone by a
plain function walking the tree:

- =[:state k]= anywhere in the view becomes =(get state k)= at render time;
- a =:actions [[…]]= prop becomes =:on-click= through the registry, whose
  spec'd multimethods are the fixed vocabulary — so an unknown action kind
  is rejected at the boundary, not discovered at the tap.

** =demo.data=

#+begin_src clojure :tangle ../../src/demo/data.clj :mkdirp true :comments link
(ns demo.data
  "The app as a map: {:state m :view hiccup}. `render` turns the view into what
  glimmer mounts — [:state k] references become values, :actions become
  :on-click closures over the registry. Data in, data out; nothing is eval'd."
  (:require [clojure.spec.alpha :as s]
            [clojure.walk :as walk]
            [demo.registry :as reg]))

;; --- the boundary ------------------------------------------------------------
(s/def ::state map?)
(s/def ::view (s/and vector? #(keyword? (first %))))
(s/def ::app (s/keys :req-un [::state ::view]))

(defn- state-ref? [x]
  (and (vector? x) (= 2 (count x)) (= :state (first x)) (keyword? (second x))))

(defn- element? [x] (and (vector? x) (keyword? (first x))))

(defn- props [el] (when (map? (second el)) (second el)))

(defn actions-in
  "Every :actions vector in the view, depth first — what validate! checks."
  [view]
  (let [found (atom [])]
    (walk/postwalk (fn [x] (when (and (element? x) (contains? (props x) :actions))
                             (swap! found conj (:actions (props x))))
                     x)
                   view)
    @found))

(defn validate!
  "Throw with an explanation unless `app` is {:state map :view hiccup} and every
  :actions vector is one the registry knows."
  [app]
  (when-not (s/valid? ::app app)
    (throw (ex-info (str "app.edn: " (s/explain-str ::app app)) {:app app})))
  (doseq [as (actions-in (:view app))]
    (when-not (s/valid? ::reg/actions as)
      (throw (ex-info (str "app.edn: bad :actions " (pr-str as) " — " (s/explain-str ::reg/actions as))
                      {:actions as}))))
  app)

;; --- the interpretation ------------------------------------------------------
(defn- substitute-state [view state]
  (walk/postwalk (fn [x] (if (state-ref? x) (get state (second x)) x)) view))

(defn- wire-actions [view]
  (walk/postwalk
    (fn [x]
      (if (and (element? x) (contains? (props x) :actions))
        (let [as (:actions (props x))
              p  (-> (props x) (dissoc :actions) (assoc :on-click #(reg/execute-actions nil as)))]
          (into [(first x) p] (drop 2 x)))
        x))
    view))

(defn render
  "The view of `app` with `state` substituted and actions wired: hiccup glimmer
  can mount. Pure, apart from the closures it makes."
  [app state]
  (-> (:view app) (substitute-state state) (wire-actions)))
#+end_src

** The challenge: jolt.http-client and iOS natives

[[https://github.com/jolt-lang/http-client][jolt-lang/http-client]] exists and works on macOS (the fx example uses it to
fetch currency rates). But it depends on =jolt-crypto=, which requires OpenSSL
natives (=libcrypto.dylib=, =libssl.dylib=). These don't exist on iOS — same
blocker as GTK4 was for the renderer. So =jolt.http-client= is not an option
for an iOS build.

The solution: call NSURLSession directly via =jolt.ffi=, the same pattern the
project already uses for UIKit. NSURLSession is built into iOS; no native deps
to bundle. The pattern mirrors the macOS demo's fx example: core.async go
blocks for concurrency, native API calls via jolt.ffi, results back through
channels.

** =demo.http= — fetch via NSURLSession (skeleton)

Documented here with `:tangle no` — the thought process, not yet tangled into
the build. The completion handler (taking NSData, NSURLResponse, NSError and
putting the result on a channel) is the tricky part; see glitter-uikit-demo's
fx example for the full block-building dance on macOS. iOS is the same API.

(Superseded — =:tangle no= — by "Dialing it in" below: a callable is not a block.)

#+begin_src clojure :tangle no
(ns demo.http
  "Fetch HTTP URLs via NSURLSession (native iOS networking). Async, via core.async.
  Returns a channel that yields {:status 200 :body \"...\"} on success, nil on error/timeout."
  (:require [clojure.core.async :as async :refer [chan put! alt! timeout go]]
            [jolt.ffi :as ffi]))

;; ObjC runtime — same bindings as glimmer-ios.ffi and screen.core
(ffi/defcfn objc-get-class    "objc_getClass"    [:string] :pointer)
(ffi/defcfn sel-register-name "sel_registerName" [:string] :pointer)
(ffi/defcfn objc-msgSend-ptr      "objc_msgSend" [:pointer :pointer] :pointer)
(ffi/defcfn objc-msgSend-ptr-1   "objc_msgSend" [:pointer :pointer :pointer] :pointer)
(ffi/defcfn objc-msgSend-ptr-2   "objc_msgSend" [:pointer :pointer :pointer :pointer] :pointer)  ; 2-arg message returning pointer
(ffi/defcfn objc-msgSend-void    "objc_msgSend" [:pointer :pointer] :void)
(ffi/defcfn objc-msgSend-int     "objc_msgSend" [:pointer :pointer] :int)

(defn cls [n] (objc-get-class n))
(defn sel [n] (sel-register-name n))
(defn nsstring [s]
  (ffi/with-c-string [c-str s]
    (objc-msgSend-ptr-1 (cls "NSString") (sel "stringWithUTF8String:") c-str)))
(defn nsurl [s]
  (objc-msgSend-ptr-1 (cls "NSURL") (sel "URLWithString:") (nsstring s)))

(defn- data-to-string
  "NSData → String (UTF-8). Returns nil if data is null."
  [data-ptr]
  (if (= ffi/null data-ptr)
    nil
    (let [len (objc-msgSend-int data-ptr (sel "length"))
          bytes (objc-msgSend-ptr data-ptr (sel "bytes"))]
      (when (pos? len)
        (String. (ffi/read bytes :uint8-array 0 len) "UTF-8")))))

(defn fetch
  "Fetch a URL over HTTP. Returns a channel that yields {:status 200 :body string}
  on success, or nil on timeout/error. `timeout-ms` defaults to 5000.

  Pattern (from screen.core's did-finish-launching): The completion handler is a
  foreign-callable with :collect-safe (so it runs safely while the main thread is
  parked in NSURLSession), and it puts results on a channel that the go block waits on."
  [url-string & {:keys [timeout-ms] :or {timeout-ms 5000}}]
  (println "fetch: starting for URL" url-string "timeout" timeout-ms)
  (go
    (let [result-ch (chan 1)
          url (nsurl url-string)
          session (objc-msgSend-ptr (cls "NSURLSession") (sel "sharedSession"))
          _ (println "fetch: got session" session)
          ;; The completion handler: receives (NSData *, NSURLResponse *, NSError *)
          ;; and puts {:status 200 :body "..."} on result-ch.
          handler-fn (fn [data response error]
                       (println "fetch: handler called for" url-string)
                       (if (not= ffi/null data)
                         (do (println "fetch: got data")
                             (async/put! result-ch {:status 200 :body (data-to-string data)}))
                         (do (println "fetch: no data, error = " error)
                             (async/put! result-ch nil))))
          ;; Foreign-callable block: takes 3 pointers, returns void
          ;; :collect-safe so it runs safely while NSURLSession owns the thread
          handler (ffi/foreign-callable handler-fn
                                        [:pointer :pointer :pointer] :void :collect-safe)
          ;; Create the task: NSURLSessionDataTask *task = [session dataTaskWithURL:url completionHandler:handler]
          ;; This is a 2-argument message, so we use objc-msgSend-ptr-2
          task (objc-msgSend-ptr-2 session (sel "dataTaskWithURL:completionHandler:") url handler)]

      ;; Resume the task to start the fetch
      (println "fetch: task pointer = " task " (null? " (= ffi/null task) ")")
      (if (or (= ffi/null task) (nil? task) (zero? task))
        (println "fetch: ERROR - task is null/nil! NSURLSession.dataTaskWithURL:completionHandler: failed")
        (try
          (do
            (println "fetch: calling resume...")
            (objc-msgSend-void task (sel "resume"))
            (println "fetch: task resumed for" url-string))
          (catch :default e
            (println "fetch: error resuming task:" e))))

      ;; Wait for result or timeout
      (async/alt!
        result-ch :has-result
        (timeout timeout-ms) nil)
      ;; If we got here and something's on the channel, read it; otherwise nil
      (or (async/poll! result-ch) nil))))
#+end_src

** Findings: NSURLSession completion handlers (2026-08-31, after exploring glitter-uikit-demo's fx example)

The macOS fx example uses =jolt.http-client='s blocking =http/get=, which works there
because jolt.http-client is available and OpenSSL natives are bundled. On iOS, that
path is closed.

The working pattern (from =screen.core='s app delegate callback):
1. A Clojure function takes the expected arguments (here: NSData, NSURLResponse, NSError pointers)
2. Wrap it in =ffi/foreign-callable= with =:collect-safe= (so it runs safely while UIKit is parked)
3. Pass the callable as an ObjC method parameter or block argument
4. When the callback fires, it has access to everything the Clojure function captured (like the result channel)

For NSURLSession, the completion handler is an ObjC block (not a method), passed to
=dataTaskWithURL:completionHandler:=. The open question: does =objc_msgSend= handle
block pointers the same way as object pointers? Likely yes (both are just pointers),
but the calling convention might differ. Testing will tell.

The architecture is sound:
- Handler fires on main thread (NSURLSession posts it there)
- Puts result on the channel via =put!=
- Go block waits with timeout via =alt!=
- Falls back gracefully if timeout or error
- `:collect-safe` ensures no memory faults while UIKit is in control

(ns demo.store
  "Documents/app.edn: the app as a file. read-app tries wire (if set) → cache → default.
  save! writes state back into the cache."
  (:require [clojure.core.async :as async]
            [clojure.edn :as edn]
            [demo.data :as d]
            [demo.default-app :as default]
            [demo.http]))

;; Wire URL, set by the calling namespace (e.g., demo.app-wire) via dynamic binding or atom.
;; If unset, only the cache and default are tried.
(defonce ^:dynamic wire-url nil)

(defn path []
  (str (or (System/getenv "HOME") ".") "/Documents/app.edn"))

(defn- read-from-wire
  "Fetch from wire-url if set. Returns validated app or nil on error/timeout."
  []
  (when wire-url
    (println "demo.store: fetching from" wire-url)
    (try
      (let [result (async/<!! (demo.http/fetch wire-url {:timeout-ms 5000}))]
        (when result
          (try (d/validate! (edn/read-string (:body result)))
               (catch :default e
                 (println "demo.store:" wire-url "is invalid —" (ex-message e))
                 nil))))
      (catch :default e
        (println "demo.store: fetch failed —" (ex-message e))
        nil))))

(defn- read-from-file
  "Load app.edn from Documents. Returns validated app or nil if not found/invalid."
  []
  (let [p (path)]
    (when-let [text (try (slurp p) (catch :default _ nil))]
      (try (d/validate! (edn/read-string text))
           (catch :default e
             (println "demo.store:" p "invalid —" (ex-message e))
             nil)))))

(defn read-app
  "The app map, in order: wire (if set) → cache (Documents/app.edn) → bundled default.
  Each stage is validated; invalid data is skipped with a message, never thrown."
  []
  (or
    (read-from-wire)
    (read-from-file)
    (do (println "demo.store: using the bundled default")
        default/app)))

(defn save!
  "Write `app` with `state` folded in. Called at :background — the only
  lifecycle moment iOS guarantees."
  [app state]
  (let [p (path)]
    (try (spit p (pr-str (assoc app :state state)))
         (println "demo.store: saved" p)

** Dialing it in: a callable is not a block (2026-08-31, later)

The "invalid memory reference" above was the runtime reading the first eight
bytes of a bare function pointer as an object's =isa=. An Objective-C block is
not a function pointer; it is a struct — Apple's [[https://clang.llvm.org/docs/Block-ABI-Apple.html][Block ABI]] — and =invoke= is
its fourth field:

#+begin_example
struct Block_literal    { void *isa; int flags; int reserved;          /* 32 bytes  */
                          void (*invoke)(void *block, ...);            /* block ptr FIRST, then the args */
                          struct Block_descriptor *descriptor; };
struct Block_descriptor { unsigned long reserved; unsigned long size; }  /* 16 bytes, size = 32 */
#+end_example

So the callable becomes the =invoke= slot of a struct built with =ffi/alloc=
and =ffi/write=, and its first argument is the block itself. =isa= is
=_NSConcreteGlobalBlock= (a =dlsym=, since it is data, not a function — no
=defcfn= can name it), and =flags= says =BLOCK_IS_GLOBAL=: the runtime then
never copies, retains or frees it, which is what makes the address stable
enough to be the key that finds the fetch's channel. It is also why the block
is never freed — =_Block_release= reads =flags= /after/ =invoke= returns —
so each fetch leaks 32 bytes, deliberately.

Two more things the first attempt had wrong, found by reading rather than
crashing:

- *A =<!!= before =ui/run= cannot be answered.* The completion arrives on
  NSURLSession's delegate queue; the proven callback path in this project is
  the main thread parked in =UIApplicationMain=, so the session is made with
  =delegateQueue: [NSOperationQueue mainQueue]= — and the main queue only
  drains inside the run loop. Fetching at launch, before the loop, is a
  deadlock by construction. The fetch moves to the =:active= lifecycle hook:
  launch from the cache instantly, refresh from the wire every time the app
  comes to the front — which is also the right product behaviour.
- *=:string= is the C string.* =objc-msg-send-1s= takes =:string= and
  converts; my =:pointer=-typed copy took a jolt string and was rejected
  ("invalid foreign-procedure argument"). =glimmer-ios.ffi= already has
  =cls=, =sel=, =nsstring=, =nsstring->str= and every =objc_msgSend= shape
  but two, so =demo.http= reuses them.

No ATS exception is needed: App Transport Security does not apply to
=localhost=, =.local= names or IP addresses — the simulator reaches the Mac
as =localhost=, the phone as its LAN address.

(Superseded — =:tangle no= — by "Content negotiation": =fetch= grew a
=:headers= option, which meant =NSMutableURLRequest= and
=dataTaskWithRequest:=. The block machinery is unchanged there.)

(ffi/defcfn msg-2p     "objc_msgSend" [:pointer :pointer :pointer :pointer] :pointer)
(ffi/defcfn msg-3p     "objc_msgSend" [:pointer :pointer :pointer :pointer :pointer] :pointer)
(ffi/defcfn msg-1p1i64 "objc_msgSend" [:pointer :pointer :pointer :int64] :pointer)
(ffi/defcfn c-dlopen   "dlopen" [:string :int] :pointer)
(ffi/defcfn c-dlsym    "dlsym"  [:pointer :string] :pointer)

(def ^:private NSUTF8StringEncoding 4)
(def ^:private RTLD-NOW 2)

;; --- the block ---------------------------------------------------------------
(defonce ^:private pending (atom {}))          ; block address -> the fetch's channel

(defn- deliver!
  "The block's invoke: (block, NSData *, NSURLResponse *, NSError *). Runs on the
  main thread, inside the run loop, while jolt is parked in UIApplicationMain."
  [block data response error]
  (when-let [ch (get @pending block)]
    (swap! pending dissoc block)
    (async/put! ch
      (if (ffi/null? error)
        {:status (u/objc-msg-send-0i64 response (u/sel "statusCode"))
         :body   (when-not (ffi/null? data)
                   (u/nsstring->str
                     (msg-1p1i64 (u/objc-msg-send-0 (u/cls "NSString") (u/sel "alloc"))
                                 (u/sel "initWithData:encoding:") data NSUTF8StringEncoding)))}
        {:error (u/nsstring->str (u/objc-msg-send-0 error (u/sel "localizedDescription")))}))))

(defonce ^:private invoke
  (ffi/foreign-callable deliver! [:pointer :pointer :pointer :pointer] :void :collect-safe))

;; delays: jolt build loads this namespace on the HOST, where none of this exists
(defonce ^:private global-block-isa
  (delay (c-dlsym (c-dlopen "/usr/lib/libSystem.B.dylib" RTLD-NOW) "_NSConcreteGlobalBlock")))

(defonce ^:private descriptor
  (delay (doto (ffi/alloc 16)
           (ffi/write :uint64 0 0)
           (ffi/write :uint64 8 32))))

(defn- make-block
  "A fresh global block around `invoke`. Never freed: the runtime reads its flags
  on release, after invoke has returned — 32 bytes per fetch, on purpose."
  []
  (doto (ffi/alloc 32)
    (ffi/write :pointer 0  @global-block-isa)
    (ffi/write :int32   8  BLOCK-IS-GLOBAL)
    (ffi/write :int32   12 0)
    (ffi/write :pointer 16 invoke)
    (ffi/write :pointer 24 @descriptor)))

;; --- the session -------------------------------------------------------------
(defonce ^:private session
  (delay (let [s (msg-3p (u/cls "NSURLSession") (u/sel "sessionWithConfiguration:delegate:delegateQueue:")
                         (u/objc-msg-send-0 (u/cls "NSURLSessionConfiguration") (u/sel "defaultSessionConfiguration"))
                         ffi/null
                         (u/objc-msg-send-0 (u/cls "NSOperationQueue") (u/sel "mainQueue")))]
           (u/objc-msg-send-0 s (u/sel "retain")))))   ; autoreleased; we keep it for the process

(defn fetch
  "GET `url`. Returns a channel that yields {:status n :body s} or {:error s}.
  Call with the loop running — the completion is delivered on the main queue."
  [url]
  (let [ch    (async/chan 1)
        block (make-block)
        task  (msg-2p @session (u/sel "dataTaskWithURL:completionHandler:")
                      (u/objc-msg-send-1p (u/cls "NSURL") (u/sel "URLWithString:") (u/nsstring url))
                      block)]
    (swap! pending assoc block ch)
    (u/objc-msg-send-0void task (u/sel "resume"))
    ch))

* Content negotiation: the app in French (2026-08-31)

The wire serves one resource at one URL. Whose language it arrives in is
/negotiation/, and HTTP already has the machinery: the request carries
=Accept-Language=, the server picks a representation and answers with
=Content-Language= and =Vary: Accept-Language=. Not =?lang=fr= — a query
param is the URL pretending to be an API, and it mints a second resource
where there is one.

Two acts.

*Act one costs no client code at all*: NSURLSession sends an
=Accept-Language= on its own, derived from the device's language settings.
A phone set to French asks for French without being told to. The server
just has to listen.

*Act two* puts the choice /in the downloaded app/: the view gains
=English= / =Français= buttons whose actions are =[[:action/set-lang "fr"]]=
— a new kind in the registry's vocabulary, whose interpretation is "remember
the language, refetch." The labels translate; the vocabulary does not —
=:action/inc= is the same word in both files, because the registry is code
and the door does not move. And the French app carries the way back to
English, since the toggle rides inside the data.

** The server learns to listen

A confession first: =scripts/serve-app= had been a loose file, written
directly and never tangled — the only script in the project outside the
notebook. It moves in here, and learns negotiation on the way. The parse
honors q-values the cheap way (stable sort, primary subtags only), which is
enough for real =Accept-Language= strings like =fr-CA,fr;q=0.9,en;q=0.8=.

#+begin_src clojure :tangle ../../scripts/serve-app :mkdirp true
#!/usr/bin/env bb
;; scripts/serve-app [PORT] — the wire, negotiated. One URL; Accept-Language
;; picks examples/counter/app.edn (en) or app_fr.edn (fr). `jolt serve`.
(require '[org.httpkit.server :as http]
         '[clojure.string :as str])

(def files {"en" "examples/counter/app.edn"
            "fr" "examples/counter/app_fr.edn"})

(defn negotiate
  "The first primary subtag, in q order, that we have a file for; else en."
  [accept]
  (let [tags (for [part (str/split (or accept "") #",")
                   :let [[tag q]  (str/split (str/trim part) #";\s*q=")
                         primary  (first (str/split (str/trim tag) #"-"))]
                   :when (seq primary)]
               [(str/lower-case primary) (or (parse-double (or q "1")) 0.0)])]
    (or (some (set (keys files)) (map first (sort-by (comp - second) tags)))
        "en")))

(let [port (Integer/parseInt (or (first *command-line-args*) "8888"))]
  (http/run-server
    (fn [req]
      (if (= "/" (:uri req))
        (let [accept (get-in req [:headers "accept-language"])
              lang   (negotiate accept)]
          (println "serve:" (or accept "(no Accept-Language)") "→" lang)
          {:status  200
           :headers {"content-type"     "application/edn"
                     "content-language" lang
                     "vary"             "Accept-Language"}
           :body    (slurp (files lang))})
        {:status 404 :body "not found"}))
    {:port port})
  (println (str "the wire, negotiated, on http://localhost:" port " — en | fr"))
  (Thread/sleep Long/MAX_VALUE))
